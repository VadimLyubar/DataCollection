# DataCollection — голосовой редактор CSV

Рефакторинг old/ExecuteAICode.py: монолит разбит на классы, глобальные переменные убраны.

## Структура src/

| Модуль | Ответственность |
|---|---|
| `constants.py` | Словарь команд WORDS, числа словами, спецзначения, заголовок CSV |
| `app_state.py` | `AppState`: загрузка/атомарное сохранение CSV, ячейки, режимы, поиск |
| `word_matcher.py` | `WordMatcher`: посимвольный конечный автомат распознавания слов |
| `commands.py` | `CommandDispatcher`: обработка команд, навигация, режимы перехода |
| `ui.py` | `UI`: отрисовка таблицы, цвета, статусная строка с индикатором режима |
| `main.py` | Сборка приложения, цикл ввода через `get_wch()` |
| `test_app.py` | Юнит-тесты логики без curses |

## Запуск

```
cd src
python main.py            # файл data.csv в корне проекта
python main.py путь.csv   # или явно указать файл
python -m pytest test_app.py -v   # тесты
```

## Формат данных

CSV с разделителем `;`, кодировка UTF-8 (читается и UTF-8-sig с BOM).
Колонки: Идентификатор;Предыдущие;Текущие.
Если файла нет — создаётся демо-версия, о чём сообщается в статусе.

## Голосовые команды

- `вперёд` / `вперед` / `дальше` / `далее` — шаг вниз по списку
- `назад` — шаг вверх
- `выше N` / `ниже N` — прыжок на N строк (сначала `перейти`, потом число, потом `выше`/`ниже`)
- `начало` / `конец` — в начало/конец списка
- `поиск`, затем текст идентификатора, затем `искать` или `найти`
- `недоступно`, `отключено` — вставка спецзначения в ячейку
- `исправить` / `очистить` — очистить ячейку, `стереть` — удалить последний символ
- `ноль`…`девять` — ввод цифры голосом; цифры с клавиатуры вводятся напрямую
- `выход` или клавиша `q` — сохранить и выйти

## Отличия от old/ExecuteAICode.py

1. `get_wch()` вместо ручного декодирования байтов (+896/+960).
2. Атомарное сохранение через временный файл и `os.replace`; ошибки записи не глушатся.
3. Модель не зависит от curses: `diff_style` возвращает строковый ключ стиля.
4. Прокрутка центрируется на активной строке (в старой — пороговое смещение через mid_point).
5. Путь к CSV задаётся аргументом командной строки.
