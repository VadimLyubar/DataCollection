# Чек-лист запуска на Android (Pydroid 3)

Цель — свести проверки на телефоне к минимуму: всё, что можно, ловим тестами на компьютере.

## Перед переносом на телефон

1. На компьютере: `python -m py_compile src/*.py` — синтаксис всех модулей.
2. На компьютере: `cd src && python -m pytest test_app.py -v` — вся логика без curses.
3. На компьютере: `python src/main.py` — прогнать руками: вперёд, назад, цифры,
   поиск (поиск → Б37 → искать), прыжок (перейти → 3 → ниже), q с сохранением.

## Перенос на телефон

1. Скопировать на телефон папку `src/` и `data.csv` (в корень проекта, рядом с src).
2. Открыть `src/main.py` в Pydroid 3 и нажать Run (треугольник).
3. Терминал в Pydroid: curses работает через встроенный эмулятор терминала.
   Если экран искажён — развернуть терминал на весь экран и перезапустить.

## Типовые проблемы Pydroid

- Нет модуля curses → обновить Pydroid 3 до актуальной версии; в старых сборках
  curses отсутствует.
- Кириллица в статусе отображается квадратиками → в настройках терминала Pydroid
  выбрать шрифт с кириллицей и кодировку UTF-8.
- Если get_wch не срабатывает на конкретном устройстве — сообщить, добавим fallback
  на getch с локально-независимым декодированием.

## Минимальная проверка на телефоне (5 минут)

1. Таблица загрузилась, заголовок и 4 демо-строки видны.
2. Ввести `123` — ячейка активной строки показывает 123.
3. Сказать «вперёд» — выделение сместилось вниз.
4. Сказать «недоступно» — ячейка стала красной.
5. Сказать «выход» — приложение закрылось; открыть data.csv и убедиться, что значение записано.
